# Marketing Funnel & Conversion Performance Analysis

## Project Overview
This project focuses on analyzing bank marketing campaign data to understand customer engagement, campaign performance, and term-deposit subscription outcomes using Power BI.

The dashboard provides insights into customer responses, subscription trends, contact methods, and campaign effectiveness through interactive visualizations and key performance indicators (KPIs).

## Objectives
- Analyze successful and unsuccessful subscriptions.
- Understand customer engagement across different occupations and education levels.
- Compare subscription outcomes by contact method.
- Identify monthly subscription trends.
- Examine call duration and campaign contact patterns.
- Evaluate overall marketing campaign performance.

## Tools & Technologies
- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations

## Dashboard Features

### Key Performance Indicators (KPIs)
1. Total Customers
2. Successful Subscriptions
3. Unsuccessful Subscriptions
4. Conversion Rate
5. Average Call Duration
6. Average Campaign Contacts

### Visualizations
1. Subscription Outcomes – Donut Chart
2. Subscription by Job – Clustered Bar Chart
3. Subscription by Education – Treemap
4. Monthly Subscription Trends – Line Chart
5. Contact Method Performance – 100% Stacked Bar Chart
6. Average Call Duration by Subscription – Clustered Column Chart
7. Campaign Contact Trends – Area Chart
8. Subscription Performance by Month – Ribbon Chart

### Interactive Filters
- Job
- Education
- Month

## Data Preparation
- Removed duplicate records.
- Checked and corrected data types.
- Reviewed missing and unknown values.
- Created calculated measures using DAX.
- Added a Month Number column for chronological sorting.
